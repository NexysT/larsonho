## 🎯 Sobre o Projeto

O **Lar de Sonho** é um website educativo desenvolvido para demonstrar **compliance total com o RGPD**, no âmbito de um projeto académico de Segurança e Proteção de Dados para Sistemas de Informação.  

O objetivo principal é mostrar como um site pode ser **bonito, funcional e totalmente compatível com privacidade de dados**.

> 💡 **Nota:** Todos os dados e conteúdos do site são fictícios.
