## 🎯 Objetivo do Projeto

O **Lar de Sonho** é um website desenvolvido com fins **académicos**, no âmbito da unidade curricular de **Segurança e Proteção de Dados para Sistemas de Informação**.

O foco principal é demonstrar:

- Implementação prática de **compliance RGPD**
- Transparência no tratamento de dados
- Boas práticas de consentimento e cookies
- Estrutura clara e acessível para o utilizador

📌 **Todos os dados apresentados são fictícios.**
